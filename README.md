README - Music party web page

Description:
------------
This is a responsive landing page created using Bootstrap framework. 
It includes a navigation bar, modal for language selection, promotional sections, 
feature highlights, and a footer with contact information.

Technologies Used:
-------------------
- HTML5
- CSS3
- Bootstrap 3
- jQuery (for modal functionality)

File Structure:
---------------
/index.html         => Main HTML file
/css/bootstrap.css  => Bootstrap CSS framework
/style.css          => Custom styles
/js/jquery.min.js   => jQuery library
/js/bootstrap.js    => Bootstrap JavaScript
/img/               => Folder for image assets

Pages:
------
- index.html       : Home page (you are here)
- services.html    : Services
- about.html       : About Us
- contectus.html   : Contact Us (Note: consider renaming to contactus.html)
- login.html       : Login page
- signup.html      : Sign-up page

How to Use:
-----------
1. Open `index.html` in a browser to view the landing page.
2. Use the navigation bar to explore different pages.
3. Click the globe icon to open the language selection modal.
4. Make sure all linked CSS/JS/image files are in their respective folders.
